# 2026-08-17

## Audit log (logger) — operator + handler implementation

Extended `com.innospots.nexus.kernel.logger` so intercepted invocations are persisted:

- `logger/operator/InvocationLogOperator.java` (new): `record(InvocationLogContext)`
  maps the framework-independent context onto `AuditLogEntity` and inserts via
  `AuditLogDao`. Path = `className#methodName`; `operatedTime` from `startTime`;
  `executionResult` = SUCCESS/FAILURE; `message` from exception or result;
  `keyParameters` = JSON of arguments (serialization failure → null, logged).
  Intentional single insert with NO `@Transactional` so audit rows survive the
  audited operation's rollback.
- `logger/handler/PersistenceInvocationLogHandler.java` (new): implements
  `InvocationLogHandler`; delegates `handle(context)` → `operator.record(...)`,
  catches `RuntimeException` and logs (never rethrows — runs in `finally`).
- Added `package-info.java` for both new `operator` and `handler` subpackages.

Verification: `mvn -B -pl innospots-nexus-kernel -am compile` → BUILD SUCCESS on
JDK 25 (installed openjdk@25 + maven via brew; local default JDK was 21, below
the project's `maven.compiler.release=25` baseline — did NOT lower baseline).

# 架构决策记录（ADR）

单项架构或技术选型决策存放于此。命名：`NNNN-<kebab-slug>.md`（如 `0001-example.md`）。

模板与级别说明见
[`skills/java/java-design/references/design-deliverables.md`](../../../skills/java/java-design/references/design-deliverables.md)
与
[`architecture-decision.md`](../../../skills/java/java-design/references/architecture-decision.md)。

完整域方案放在 `docs/design/` 或各模块 `docs/`，ADR 只记录「一件事一个决策」，并在相关设计文档中链接。

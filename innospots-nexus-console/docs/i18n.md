# Console 国际化

## 资源目录

语言包由 `innospots-nexus-platform` 持有，位于
`innospots-nexus-platform/src/main/resources/i18n/console/`，按 Console 页面域划分：

```text
i18n/console/
├── namespaces
├── access/
├── audit/
├── auth/
├── common/
├── dictionary/
├── invite/
├── menu/
├── organization/
├── platform-user/
├── plugin/
└── role/
```

`namespaces` 是纯文本 namespace 索引，每行一个名称，决定默认加载顺序。namespace
直接使用字符串，不定义 Java 枚举。

每个目录包含 Spring MessageResource 结构的文件：

- `messages.properties`：默认中文 `zh-CN`
- `messages_en.properties`：英文 `en-US`
- 可按 Spring 约定追加 `messages_en_US.properties`；语言专属文件覆盖默认文件，
  缺失键继续回退到 `messages.properties`

键名必须以所属 namespace 开头，例如：

```properties
role.role-list.body.title=角色管理
role.role-list.props.emptyText=暂无角色
```

页面作者态 YAML 不需要逐字段添加 `$i18n`。`innospots-nexus-ui-console` 在服务端按
`<namespace>.<pageId>.<DSL path>` 查找词条；未命中时保留 YAML 中文源文。

## 公共接口

```http
GET /api/public/i18n/bundles
```

查询参数：

| 参数 | 说明 |
|------|------|
| `appId` | 应用标识，缺省或 `console` |
| `locale` | `zh-CN` / `en-US`，支持 `zh`、`zh_CN`、`en`、`en_US` 别名 |
| `namespaces` | 逗号分隔 namespace；缺省加载全部 |
| `release` | 发布标识，仅接受 `[A-Za-z0-9._-]{1,64}` |

语言优先级：显式 query > `nexus.locale` Cookie > `Accept-Language` > `zh-CN`。

接口无需登录或功能权限，响应为统一 `R<T>`，`data` 为 Pactor `simple-v1`：

```json
{
  "appId": "console",
  "locale": "en-US",
  "release": "console-ui",
  "format": "simple-v1",
  "bundles": {
    "common": {
      "version": "<sha256>",
      "messages": {
        "common.action.save": "Save"
      }
    }
  }
}
```

## Next.js 对接

`@innospots/ui-console` 的服务端语言层：

1. 从 query、`nexus.locale` Cookie、`Accept-Language` 解析 locale。
2. 服务端调用 Java `GET /api/public/i18n/bundles` 并拆解 `R<T>.data`。
3. 校验 `simple-v1` 结构，按进程缓存并在后端不可用时回退 YAML 中文源文。
4. 在 `/api/sitemap`、`/api/public/pages/{id}` 下发本地化后的 sitemap、菜单、布局和页面 DSL。
5. `/api/i18n/locale` 写入语言 Cookie 后整页刷新，重新构建语言上下文并重新加载页面。

代码内静态文案使用 `useUiText()`；词条键由中文源文的稳定 FNV-1a 哈希生成，
因此源码文案不得随意改写，改写时需同步更新 `common/messages*.properties`。

## 校验

```bash
mvn -pl innospots-nexus-platform -am clean compile
mvn -pl innospots-nexus-console -am \
  -Dtest=MessageBundleLoaderTest,MessageBundleServiceTest,I18nStatusCodeTest,I18nBundleEndpointContractsTest \
  -Dsurefire.failIfNoSpecifiedTests=false test
mvn -pl innospots-nexus-platform -am \
  -Dtest=PlatformMessageBundlesTest \
  -Dsurefire.failIfNoSpecifiedTests=false test
```

修改资源后应确认：索引包含全部目录；中英文 key 集合一致；所有 key 使用所属
namespace 前缀。

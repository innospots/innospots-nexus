# 评审检查清单

按分组组织。每条给出「查什么」与「判不合格的信号」。
快速红线版见 `java:reference` 的 `quick-constraints.md`。

---

## A. 边界与归属

| 检查项 | 不合格信号 |
|--------|-----------|
| Maven 模块归属正确 | 业务能力错放在 `base`/`core`；基础设施塞在业务模块 |
| 业务域归属正确 | 相邻域概念混在一个域里 |
| 遗留代码只作行为参考 | diff 中出现遗留源码、遗留 POM 结构、机械复刻的包名 |
| 依赖方向单向 | `kernel` ↔ `platform` 互引；反向依赖高层 |
| 未创建投机分层 | 空的 `model`/`service`/`event` 包 |

---

## B. 命名

| 检查项 | 不合格信号 |
|--------|-----------|
| 类型后缀匹配实际职责 | 用 `Manager`/`Helper`/`Processor`/`Utils` 当万能兜底 |
| 方法动词揭示结果形态 | `getAll`、`queryXxx`、`process`、`execute`、`doWork` |
| 请求名表达操作与修改权 | 一个笼统 `XxxRequest` 承担不同修改权 |
| VO 名表达用例 | 大写 `VO`、`Dto`、`Response`、`Result` |
| 字段语义明确 | `data`/`info`/`item`/`flag`；裸 `timeout`；无后缀的计数 |
| 布尔命名 | `isEnabled` 字段；`notDisabled` 这类否定式 |
| 缩写大小写一致 | `pluginID` 与 `pluginId` 混用；`DAO`/`Dao` 混用 |
| 包名表达边界 | `impl`/`common`/`misc`/`util` 子包；复数包名 |
| 一概念一词 | 同一个概念在端点/实体/DAO/库中用了不同的词 |

---

## C. 代码风格

| 检查项 | 不合格信号 |
|--------|-----------|
| 花括号与缩进 | 单行裸 `if`；Tab 缩进 |
| 行宽 120 | 超长行未折行 |
| 导入顺序 | 三组顺序错；通配符导入 |
| 成员顺序 | 常量/字段/构造器/public/protected/private 混乱 |
| Lombok | `@Data`；`@Sl4j` 拼写；手写 logger；敏感字段进 `toString` |
| 集合 | 返回内部可变集合；未防御拷贝；用 `null` 表示空集合 |
| 日志 | `System.out`；`printStackTrace`；字符串拼接；逐层重复记录 |
| 字面量 | 领域魔法值未提为常量；嵌套三元 |

---

## D. 注释

| 检查项 | 不合格信号 |
|--------|-----------|
| public 类型有 Javadoc | 缺失，或只复述类名 |
| public/protected 方法有 Javadoc | `@param`/`@return`/`@throws` 缺失 |
| 行内注释解释 why | 复述代码在做什么 |
| TODO 规范 | 裸 `TODO`/`FIXME`；用 TODO 为伪造成功或吞异常开脱 |
| 无注释掉的代码 | 存在大段被注释的实现 |
| 无变更历史 | 作者、日期、工单号写进注释 |
| 注释未承诺未实现行为 | 注释描述的行为与实现不符 |

---

## E. 持久化

| 检查项 | 不合格信号 |
|--------|-----------|
| 基类与范围正确 | 工作区数据用了 `BaseEntity`；自造 `ProjectBaseEntity` |
| 主键注解完整 | 缺 `@TableId`/`@Id`/`@Column(length=32)`；operator 手工赋主键 |
| `TABLE_NAME` 常量复用 | 注解里写字面量，或两处不一致 |
| 字符串长度为 2 的幂 | 任意长度；该用 `@Lob` 却给了个大长度 |
| 索引匹配访问模式 | 唯一查找无唯一索引；索引名无意义或不带表概念 |
| 未重复继承字段 | 实体里又声明 `tenantId`/`createdAt` 等 |
| 单表无 join | DAO 中出现 join；存在 Mapper XML |
| 无 N+1 | 循环内逐行查关联表 |
| 跨表写有事务 | 多表写入分散在无事务的 operator 中 |

---

## F. 端点

| 检查项 | 不合格信号 |
|--------|-----------|
| 只用 `jakarta.ws.rs` | 出现 `@RestController`/`@GetMapping` 等 |
| 类级路径 + 方法级 HTTP 注解 | 路径散落；资源路径写在方法上 |
| 参数显式注解 | 依赖隐式绑定 |
| 返回 `R<T>` | 返回裸实体、`Map`、null |
| 推迟行为显式失败 | 返回伪造成功数据或空数据 |
| 不直接依赖 DAO | 端点注入了 DAO |
| 边界内聚 | 生命周期与成员/分配混在一起；管理写与运行时读混在一起 |
| 方法数 | 超过约 7 个内聚操作未做边界复审 |
| 命名与 service 一致 | 出现 `process`/`handle`/`execute` |

---

## G. 分层与依赖注入

| 检查项 | 不合格信号 |
|--------|-----------|
| 依赖方向 | `endpoint → service → operator → dao` 被打破 |
| operator 不依赖 service/operator | operator 注入了 service 或另一个 operator |
| service/operator 不返回 `R<T>` | 下层构造了响应包装 |
| 构造器注入 + `final` | 字段注入、依赖 setter |
| 接口有真实边界理由 | 仅为 mock 而建的接口 |
| 契约按能力命名 | 机械加 `I` 前缀或 `Impl` 后缀 |

---

## H. 异常与状态码

| 检查项 | 不合格信号 |
|--------|-----------|
| 用 `NexusException` + 类型化 `StatusCode` | `IllegalArgumentException`/`Objects.requireNonNull` 做业务校验；每错误一个异常子类 |
| 全码九字符 | 长度不符；`bisCode()` 与 `fullCode()` 不一致 |
| 类别按语义 | 因 HTTP 映射方便而选类别 |
| 本地码未占用且稳定 | 与既有码冲突；为让列表好看而重排既有码 |
| 双语 message/advice | 只有英文；两 locale 复制粘贴 |
| cause 保留 | 翻译时新建异常替换掉原始 cause |
| 无敏感值 | 状态文本或响应含密钥、令牌、ID、SQL、路径、堆栈 |
| 捕获最窄异常 | `catch (Exception)` 后返回伪造成功 |
| 中断处理 | 吞掉 `InterruptedException`；未恢复中断标志 |
| 集中映射 | 端点里逐个方法做异常到响应的映射 |
| 归属正确 | 领域状态放错模块；kernel/platform 互引状态枚举 |
| 新增前已搜索 | 造了与现有码同义的新码 |

## I. 事务与并发

| 检查项 | 不合格信号 |
|--------|-----------|
| 只用 `jakarta.transaction.Transactional` | 出现 Spring 事务注解 |
| 方法级最小写操作 | 默认类级注解；大范围事务 |
| 多写有事务 | 多 DAO 写入散落且无事务 |
| 长事务 | 事务内含远程调用、文件 I/O、大批量循环 |
| 线程安全已声明 | 可变 public 类型无策略说明 |
| 同步机制清晰 | 混用 synchronized/原子类/并发集合而无解释 |
| 不持锁回调 | 持锁时调用插件/事件处理器/回调 |
| 返回快照 | 返回注册表/配置/指标的实时可变视图 |
| 幂等靠唯一性 | 只靠「先读再写」保护幂等 |

## J. 领域事件

| 检查项 | 不合格信号 |
|--------|-----------|
| 事件是不可变 record | 事件里塞了 DAO、service、可变实体 |
| 发布域拥有契约 | 事件放在消费域或随意挪到 core |
| 成功后才发布 | 写入/事务可能失败就先发成功事件 |
| 通知用 `publish` | 默认使用 `publishSync` |
| 订阅有清理 | 注册后不 `unsubscribe` |
| 处理器在自身 handler 包 | 发布方依赖消费方 handler |
| 类型串稳定 | 内部重构时重命名了已发布的类型串 |
| 载荷兼容 | 删改了既有消费者依赖的字段语义 |

## K. 依赖与构建卫生

| 检查项 | 不合格信号 |
|--------|-----------|
| 版本只在 BOM | 模块 POM 内联 `<version>` |
| 无未声明依赖 | `dependency:analyze` 报 `Used undeclared` |
| 无未使用依赖 | 报 `Unused declared`（注意 provided 误报） |
| 无版本冲突 | 依赖树中出现非 BOM 路径的版本覆盖 |
| `base` 零中间件 | `base` 的 POM 出现数据库/框架依赖 |
| `core` 不绑 Spring Boot 自动配置 | `core` 出现自动配置类 |
| 模块职责符合 `AGENTS.md` | 业务能力错放 |
| 新增依赖已选型评估 | 直接引入未评估的第三方库 |

## L. 安全

| 检查项 | 不合格信号 |
|--------|-----------|
| 日志无敏感值 | 记录密码、令牌、密钥、解密载荷、敏感配置 |
| 状态文本无敏感值 | `message()`/`advice()`/`display()` 含密钥、ID、SQL、路径、堆栈 |
| 响应不泄露内部 | 响应含 cause 链、类名、SQL、文件路径、供应商诊断 |
| `toString` 保护 | 凭据类字段进入 Lombok 生成的 `toString` |
| 不用 `@Data` | 领域/持久化类型使用了 `@Data` |
| 校验完整 | 只依赖数据库约束做应用层可表达的校验 |
| 未知失败兜底 | 未记录、未映射，或直接把内部信息抛给调用方 |

## M. 性能

| 检查项 | 不合格信号 |
|--------|-----------|
| 无 N+1 | 循环内逐行查关联表 |
| 事务范围合理 | 类级注解；简单单表读包事务 |
| 无长事务 | 事务内含远程调用或批量循环 |
| 分页生效 | 一次性载入全表 |
| 无重复计算 | 循环内重复查询同一稳定数据 |
| 无持锁回调 | 持锁调用外部代码 |
| 资源有生命周期 | 线程/执行器/客户端创建后无清理路径 |

## N. 兼容性

| 检查项 | 不合格信号 |
|--------|-----------|
| 未顺手改兼容面 | 重命名 public 类型/签名、REST 路径与字段、枚举值、状态码 |
| 未改持久化标识 | 改 `nx_` 表名、稳定业务键、实体 ID 前缀 |
| 未改契约标识 | 改事件类型串、配置键、插件 ID、能力键、序列化字段名 |
| 废弃规范 | 只用 `@Deprecated` 而缺 `@deprecated`；未指明替代方案与兼容期 |
| 追加式改动的默认值 | 新增字段未为旧调用方与既有数据定义默认值 |

## 判定与输出

| 判定 | 标准 |
|------|------|
| 通过 | 无阻塞项；警告项已记录并说明原因 |
| 有条件通过 | 存在警告项但无阻塞项，且遗留项已明确责任与时限 |
| 不通过 | 存在任一阻塞项，或 L0–L4 任一命令失败 |

阻塞项包括：红线违反、编译/测试失败、安全泄露、依赖方向错误、兼容面无方案改动。

每个问题输出必须包含：级别、`path:line`、问题描述、修正建议。

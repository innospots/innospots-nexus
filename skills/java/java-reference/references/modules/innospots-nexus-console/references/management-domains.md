# 角色、字典与菜单域

| 域 | REST | 说明 |
|----|------|------|
| **role** | `/console/roles`、`.../bindings` | `RoleService`、`RoleOperator`、实体 `RoleEntity` |
| **dictionary** | `/console/dictionary-types` | TENANT 归属字典 CRUD |
| **menu** | 无管理 REST | `MenuEntity` 供库内能力；运行时侧栏见 **navigation** |

包级参考：`role-*.md`、`dictionary-*.md`、`menu-*.md`。

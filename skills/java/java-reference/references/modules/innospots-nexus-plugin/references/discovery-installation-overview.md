# 发现与安装

| 包 / 类型 | 说明 |
|-----------|------|
| `discovery.*` | classpath 扫描、`PluginCatalog`、定义编译 |
| `installation.service.*` | `PluginInstallationManager`、`PluginRuntimeFactory` |
| `installation.domain.*` | 安装实体、枚举、`PluginManagementView` |
| `installation.repository.*` / `dao.*` | 安装表持久化 |
| `installation.bootstrap.PluginHostBootstrap` | 宿主启动编排 |
| `dependency.*` | 插件依赖解析 |
| `config.*` | 默认插件配置 |

包级参考：`discovery.md`、`installation-*.md`、`dependency.md`、`config.md`。

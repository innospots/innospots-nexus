# 包 `i18n`

## I18n

**类型：** annotation

Jackson 注解，标记字段在序列化时自动进行 i18n 翻译。 字典来源二选一（注解优先）： {@link #value()} — i18n 键，如 "${app.title"} 或裸键 app.title 成员变量值 — I18nObject、${key} 字符串、嵌套 Map/List 等（见 I18nConverter）


## I18nConverter

**类型：** class

核心 i18n 翻译引擎。支持两种翻译模式： i18n 键解析 — 包裹在 ${key} 中的字符串通过 I18nMessageResolver 解析。 I18nObject 翻译 — I18nObject 实例返回当前线程本地 Locale 对应的值。 当前语言环境存储在 ThreadLocal 中，可通过 {@link #setLocale(Locale)} 设置。

### 方法

#### `setLocale(Locale locale) → void`
- **说明：** 设置当前线程的 i18n 解析语言环境。
- **参数：**
  - `locale` — 语言环境；为 null 时清除（回退到系统默认）

#### `locale() → Locale`
- **说明：** 返回当前线程的语言环境，回退到 JVM 默认值。
- **返回：** 当前语言环境

#### `setMessageResolver(I18nMessageResolver resolver) → void`
- **说明：** 注册全局消息解析器。使用原子引用，可在应用启动时设置一次。
- **参数：**
  - `resolver` — 消息解析器

#### `ignoreI18n() → void`
- **说明：** 全局禁用当前线程的 i18n 翻译。 / public static void ignoreI18n()

#### `shouldIgnoreI18n() → boolean`
- **说明：** 返回当前线程是否全局禁用了 i18n 翻译。
- **返回：** 禁用时返回 true

#### `clear() → void`
- **说明：** 清除所有线程本地状态及消息解析器。 / public static void clear()

#### `isI18nField(String value) → boolean`
- **说明：** 判断字符串是否为 i18n 键表达式（包裹在 ${...} 中）。
- **参数：**
  - `value` — 待检查的字符串
- **返回：** 是 i18n 键时返回 true

#### `isI18nObjectType(Class<?> type) → boolean`
- **说明：** 判断类型是否为 I18nObject 或其子类。
- **参数：**
  - `type` — 待检查类型
- **返回：** 是 I18nObject 类型时返回 true

#### `isI18nObjectShape(Object value) → boolean`
- **说明：** 判断运行时值是否可解析为 I18nObject： I18nObject 实例、非空字符串，或键均为语言标签且值为字符串的 Map。
- **参数：**
  - `value` — 待检查值
- **返回：** 符合 I18nObject 形态时返回 true

#### `parseI18nObject(Object value) → I18nObject`
- **说明：** 将字符串、Map 或已有 I18nObject 规范化为 I18nObject。
- **参数：**
  - `value` — 源值
- **返回：** 解析结果；源值为 null 时返回 null

#### `i18nName(String value) → String`
- **说明：** 从包裹表达式中提取 i18n 键名。 对 "${user.name"} 返回 "user.name"。
- **参数：**
  - `value` — 包裹表达式
- **返回：** 键名；非 i18n 字段时返回 null

#### `wrapKey(String key) → String`
- **说明：** 用 i18n 前缀/后缀包裹键字符串：key -> "${key"}。
- **参数：**
  - `key` — 原始键
- **返回：** 包裹后的表达式

#### `translateAnnotatedField(String annotationKey, Object fieldValue) → Object`
- **说明：** 按 I18n 注解与字段值翻译。 当 annotationKey 非空时，优先将其视为 i18n 键（可写 ${key} 或裸键 key）； 否则对 fieldValue 执行 {@link #translate(Object)}。
- **参数：**
  - `annotationKey` — I18n；为空时忽略
  - `fieldValue` — 成员变量当前值
- **返回：** 翻译后的 JSON 可写入值

#### `toKeyExpression(String key) → String`
- **说明：** 将裸 i18n 键或已包裹的 ${key} 表达式规范化为 ${key} 形式。
- **参数：**
  - `key` — 裸键或包裹表达式
- **返回：** 规范表达式

#### `translate(Object value) → Object`
- **说明：** 递归翻译对象： I18nObject — 按当前语言环境查找 String — 若为 i18n 键表达式则解析 Map/List — 递归翻译条目 其他类型 — 原样返回
- **参数：**
  - `value` — 待翻译的值
- **返回：** 翻译后的值

#### `translateString(String value) → String`
- **说明：** 翻译单个字符串。若为 i18n 键（${key}），通过消息解析器解析。 支持内联默认值语法 ${key:default} 及以 |#| 分隔的语言环境配对默认值。
- **参数：**
  - `value` — 待翻译的字符串
- **返回：** 翻译后的字符串

#### `isChineseLocale(Locale locale) → boolean`
- **说明：** 判断给定语言环境是否为中文变体。
- **参数：**
  - `locale` — 语言环境
- **返回：** 是中文时返回 true

#### `isEnglishLocale(Locale locale) → boolean`
- **说明：** 判断给定语言环境是否为英文变体。
- **参数：**
  - `locale` — 语言环境
- **返回：** 是英文时返回 true


## I18nMessageResolver

**类型：** interface

将 i18n 键解析为本地化消息字符串的策略接口。 实现可从资源包、数据库或任何其他存储加载消息。


## I18nObject

**类型：** class

表示国际化字符串的语言环境到值的映射。 提供带回退的语言环境感知查找：精确匹配（如 zh-CN）→ 仅语言（zh）→ 首个可用值。

### 方法

#### `of(String value) → I18nObject`
- **说明：** 创建仅包含默认语言（en）单个值的 I18nObject。
- **参数：**
  - `value` — 默认值
- **返回：** I18nObject 实例

#### `of(String locale, String value) → I18nObject`
- **说明：** 创建包含单个语言环境-值对的 I18nObject。
- **参数：**
  - `locale` — 语言环境
  - `value` — 值
- **返回：** I18nObject 实例

#### `of(Map<String, String> values) → I18nObject`
- **说明：** 从现有语言环境-值映射创建 I18nObject。
- **参数：**
  - `values` — 源映射
- **返回：** I18nObject 实例

#### `of(String... pairs) → I18nObject`
- **说明：** 从语言环境-值对创建 I18nObject。 示例：I18nObject.of("en", "Hello", "zh", "你好")
- **参数：**
  - `pairs` — 交替的语言环境、值、语言环境、值……
- **返回：** I18nObject 实例

#### `defaultValue() → String`
- **说明：** 返回当前线程语言环境对应的值。
- **返回：** 本地化值

#### `enValue() → String`
- **说明：** 返回英语（US）值。
- **返回：** 英文值

#### `cnValue() → String`
- **说明：** 返回简体中文值。
- **返回：** 中文值

#### `value(Locale locale) → String`
- **说明：** 按以下回退顺序解析给定语言环境的值： 精确匹配（如 zh-CN）→ 仅语言（zh）→ 同语言组的其他变体 → 首个可用值。
- **参数：**
  - `locale` — 目标语言环境
- **返回：** 解析后的值；映射为空时返回 null

# Package `i18n`

## I18n

**Type:** @interface

Jackson annotation that marks a field for automatic i18n translation during serialization.

## I18nConverter

**Type:** class

Core i18n translation engine.

## I18nMessageResolver

**Type:** interface

Strategy for resolving an i18n key to a localized message string.

## I18nObject

**Type:** class

A locale-to-value map representing an internationalized string.

# 包 `i18n`

## I18nMessageResolver

**类型：** interface

将 i18n 键解析为本地化消息字符串的策略接口。 实现可从资源包、数据库或任何其他存储加载消息。

## I18nObject

**类型：** class

表示国际化字符串的语言环境到值的映射。 提供带回退的语言环境感知查找：精确匹配（如 {@code zh-CN}）→ 仅语言（{@code zh}）→ 首个可用值。

### 方法

#### `of(String value) → I18nObject`

- **说明：** 创建仅包含默认语言（en）单个值的 I18nObject。
- **参数：**
  - `value` — 默认值
- **返回：** I18nObject 实例

#### `of(String locale, String value) → I18nObject`

- **说明：** 创建包含单个语言环境-值对的 I18nObject。
- **参数：**
  - `locale` — 语言环境
  - `value` — 值
- **返回：** I18nObject 实例

#### `of(Map<String, String> values) → I18nObject`

- **说明：** 从现有语言环境-值映射创建 I18nObject。
- **参数：**
  - `values` — 源映射
- **返回：** I18nObject 实例

#### `of(String... pairs) → I18nObject`

- **说明：** 从语言环境-值对创建 I18nObject。 示例：{@code I18nObject.of("en", "Hello", "zh", "你好")}
- **参数：**
  - `pairs` — 交替的语言环境、值、语言环境、值……
- **返回：** I18nObject 实例
- **异常：** IllegalArgumentException 参数个数为奇数时

#### `defaultValue() → String`

- **说明：** 返回当前线程语言环境对应的值。
- **返回：** 本地化值

#### `enValue() → String`

- **说明：** 返回英语（US）值。
- **返回：** 英文值

#### `cnValue() → String`

- **说明：** 返回简体中文值。
- **返回：** 中文值

#### `value(Locale locale) → String`

- **说明：** 按以下回退顺序解析给定语言环境的值： 精确匹配（如 zh-CN）→ 仅语言（zh）→ 同语言组的其他变体 → 首个可用值。
- **参数：**
  - `locale` — 目标语言环境
- **返回：** 解析后的值；映射为空时返回 null

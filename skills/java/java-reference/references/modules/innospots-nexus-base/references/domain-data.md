# 包 `domain.data`

## DataBody

**Type:** class

自带计时的数据载荷。

## DataOperation

**Type:** enum

在目标数据源上执行的数据操作类型。

## DataPage

**Type:** record

不可变的分页数据容器。

## DataRequest

**Type:** class

对命名目标数据源执行 `DataOperation` 的请求。

## DataResponse

**Type:** class

数据操作的通用响应封装。

## DataSchema

**Type:** class

描述数据载荷结构：`DomainField` 列表及自由格式的配置项。
